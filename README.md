# 🎓 自用 小论文写作 AI Prompt

这是一个专为学术论文写作设计的 AI Prompt 工作流合集。通过 8 个循序渐进的对话轮次，引导 AI 从选题、文献检索、大纲构建，一直到全文撰写、学术润色及排版输出。


## 📝 第一轮：列出大概选题范围

```
**【提交课程材料】**
这是我【课程名】课程的课程材料。现在需要完成一篇期末论文/学期论文/课程论文。下面是对论文的要求：

**【粘贴论文要求】**
语言与字数要求：英语/中文，**【… words/字】**

现在帮我思考选题。根据论文要求的选题范围，帮我列举出一些可以选择的方向。

* **【导师/指导老师的研究方向是：……】**
* **【我的个人研究兴趣是：……/我想做关于[具体行业/领域]的研究】**
* **【我想避免的研究方向是：……】**

**选题要求：**

1. 选择方向必须与课程内容有关，比如涉及课程中的一位作家或一部作品；
2. 切入点小，从小选题，避免选择过大的题目。选题的难度要适当，符合【…专业】【本科生/硕士生/博士生】的学术水平；
3. 理论性强。根据相关已有文献，推荐一些可以用于解释、有代表性、且具有阐述价值的相关理论（包括文学、语言学、心理学、历史学等等人文社科理论）；
4. 保证一定创新性。结合现有研究中的空白，提出具有一定填补空白潜力的选题，确保该选题能够推动学科的理论发展或实践应用。

**输出要求：**
包含「题目范围」和「理论」两个模块，在题目范围中列举出对应的作家/作品/理论，再列举出可以应用的「理论」模块中的理论及其简介。
```


## 🛠️ 第二轮：修改选题方案

```
选择【第几个】方案。
但是我觉得这个选题有点：
**【太宽泛，范围不够清晰 / 太模糊，研究问题不具体 / 太复杂，涉及太多变量 / 其他问题：[描述]】**

请帮我改进这个选题：

1. 确定具体的研究对象（作家作品、文学理论、人群、组织、行业等）
2. 明确具体的研究问题，将你选定的这个方向与【方案N/理论/作家/作品】相结合/比较
3. 控制研究范围（不要涉及太多变量）
4. 确保有研究空白（这个角度是否前人已经研究过）

请给我 3-5 个改进版本的选题，并解释每个版本的改进点。
```


## ⚖️ 第 2.5 轮：如果对选题有犹豫
```
我现在在这几个选题之间犹豫：**【主题一 / 二 / 三 / ……】**

请帮我从多个维度对比这些选题：

1. **创新性对比**：哪个选题最创新？
2. **可行性对比**：哪个选题更加贴近【本科生/研究生/博士生】应该达到的学术水平？哪个选题最容易完成？各自的主要困难是什么？
3. **学术价值对比**：哪个选题最有学术价值？对该领域的贡献大小排序？
4. **资源需求对比**：哪个选题所需资源最少？各自的资源短板是什么？
5. **最后的推荐是什么**？为什么？
6. 如果非要在这三个之间选一个，我应该选哪个？理由是什么？
```


## 📚 第三轮：明确选题，查找文献
```
我选定【第几个】方案作为我撰写论文的方向，现在利用权威文献平台查找与该方向最为贴近 / 选题内容较为相似 / 相关研究对象权威度较高的论文文献（仅限正文为中文、英文的文献，正文是其他语种的不采用，作者姓名或国籍采用其他语种但用英语撰写的论文也可以采用）。

**输出格式：**

1. **首先输出论文列表**：标题，作者，作者单位，撰写年份，期刊，是否为核心，期刊评级，相关度，影响因子等文献信息，请你建立一个论文数据库，以表格形式呈现，表格列包括：
`| 序号 | 论文标题 | 作者 | 年份 | 期刊/会议 | 研究类型 | 主要方法/理论 | 中心论点/主要发现 | 相关性（相关性：1-5分，5最相关） | 优先级（优先级：★★★★★ 到 ★ 共5个等级） |`
2. **文献综述**：用一两段话说清楚目前通过查找文献得出的初步结论，当前研究趋势/研究方向，前人已经解决了什么问题/研究过哪些问题，有哪些当前概念的有奠基性的早期论文，梳理文章演进脉络，详细说明每一篇关键论文是如何启发后者的，它们之间有什么继承或修正关系；
3. **精选解读**：列出 5-10 篇最有代表性的论文，最好来自谷歌学术或国际知名期刊。【选择性：要去至少包含 N 篇中文文献/英文文献。】每篇论文用一段通俗易懂但详细的中文，说清楚它的主题、中心论点、核心贡献或解决了什么具体问题。

```

## 🏗️ 第四轮：确定框架结构

**【上传相关核心资料，例如作品原文、作家介绍等等原始性或总结性但不一定属于参考文献的资料】**

```
根据选题、查找到的文献和我上传的【文学作品原始资料/介绍性材料】构建文章正文部分框架，包括：论点，论证，结论，分为若干部分。

**【我想要论文包含以下内容：**
**背景/问题、作家作品简介、文学理论介绍、用理论解释作品、作家作品比较、文化背景简析、研究设计、主要方法、关键发现/结果、理论意义、实际应用、反思总结、…………（结合实际论文情况选择）】**

请设计论文的最优结构：

1. 各部分的内容和重点
2. 各部分的预期字数
3. 各部分对应的表格/图表（如有）
4. 逻辑流畅的关键是什么
5. 哪些部分是论文应该强调的「卖点」

**框架要求**逻辑严密环环相扣，不要像传统论文一样过于死板，但也不要过于跳脱显得没有逻辑思维和学术素养。
```


## ✍️ 第五轮：撰写论文全文

**【上传所有的参考文献。若无法一次性传完，就分批次传。prompt：这是我的部分参考文献，我接下来会继续上传参考文献】**
本轮对话中我上传的就是你需要用到的参考文献。
```
根据下面的框架撰写论文全文：
**【粘贴你修改过的上轮对话中AI给出的框架】**

**论文内容需要包括：**

1. 摘要和关键词（3-5个）。摘要应简述论文的主要内容、目的及结论。
2. 正文；
3. 引用文献列表。

**撰写要求：**

1. **关于内容**：严格按照论文撰写要求撰写，严格按照目标语言【英文/中文】**和**【】字/词数要求撰写，字数可以多不能少；不可以只空谈理论，必须结合实例/文本。如果是对文学作品的解读，论据需要引用原文内容；
2. **关于结构**：逻辑紧密，符合框架结构；
3. **关于段落和分点**：可以列小标题，但是正文部分只允许成段书写，不允许在正文段落中分点；
4. **关于语言**：语言自然流畅，少用复杂晦涩句，不要堆砌辞藻，尽量用较为简单的语言论证深刻道理；尽量不用比喻或其他简单文学修辞手法撰写文本，避免使用奇怪比喻；正文中避免「短语+冒号」小标题，尝试将标题内容融入正文，或改用完整的短句表达；避免重复表达，灵活替换同义词，改变句式结构，或增加新的信息点；禁止使用「不是……而是……」句型（包括 It’s not…. It’s….）；禁止使用「当……」；禁止使用破折号、扩号、冒号给正文文本做注释；禁止使用「稳稳接住」「I catch you」这种表达；
5. **关于参考文献及引用**：
* 只允许引用我给你上传的文献内容或你列出文献列表中的文献，不允许引用其他文献；
* 禁止杜撰文献信息、文献内容，引用内容/观点直接来源于我上传的原始文献文件，不允许杜撰与原始文献相左的观点或内容；
* 在正文中引用可以采用直接引用、间接引用相结合的方式。论文中引用的部分，在对应语句后用括号标注，例如：「xxx。（张三，2023）」
* 引用部分不得超过全文的20%；
* 至少引用【】**篇中文文献/**【】**篇外文文献/**【引用我提供的所有文献】；
* 在参考文献列表中，英文文献使用 MLA 格式标注，中文文献用 GB/T 7714-2015 标准格式标注。
```

```

As an academic essay writing assistant, paraphrase the comprehensive part of the paper using more academic and scientific language. Use a neutral tone and avoid repetitions of words and phrases. Don't use too advanced words and make sure it's easy to read. After polishing, use **【】** to mark the polished text.
```

```
检查这篇文献的学术质量，请从以下几个方面进行评估：

1. **文献的代表性**：是否包含了该领域的关键论文？
2. **分析的深度**：是否进行了深入分析？是否提出了新的见解或框架？

**【输出详细的检查报告/直接修改我的论文，一次性输出完整版】**
```


## 🛡️ 第七轮：降 AI 率
```
**【角色设定】**
你现在是一位拥有20年顶尖核心期刊审稿经验的人文社科领域（文学、语言学、历史学等）资深学术编辑。你的核心任务是：接收一段初稿文本，对其进行“去AI化”深度润色与重构。

**【核心目标】**
消除文本中机器生成的刻板痕迹（机械对称、空泛宏大、结构模板化），将其重构为符合人类优秀学者写作习惯的文本。在增加思维流动性与人文气息的同时，**必须严格遵守学术规范，保持论证的严密性、概念的精确度以及学术文本应有的典雅与克制，绝不可将其修改为随意的网络口语。**

**【执行准则】**

**1. 严格禁用“AI招牌词汇”（Banned Vocabulary）：**

* **中文黑名单：** 值得注意的是、简而言之、毋庸置疑、革命性的、见证了、深刻的、沉浸式的、其实 等
* **英文黑名单：** delve into, testament to, navigate, landscape, tapestry, intricate, transformative, revolutionize, unwavering, shed light on, paramount, etc.

**2. 打破机械结构与节奏（Structural Asymmetry）：**

* **拒绝模板过渡：** 一定程度上避免八股文式的枚举连接词。
* **学术逻辑衔接：** 使用符合人类逻辑推演的隐性过渡。
* **错落的句式：** 坚决打破段落等长的AI特征。采用“长句作缜密推理，短句抛出核心论断”的呼吸感节奏。拆分过度冗长的复合句，消除套路化的“从 X 到 Y”句式。减少破折号（——）和冒号（:）的滥用。

**3. 注入“学者语态”与严谨性（Academic Voice & Hedging）：**

* **学术辩证与批判思维：** 拒绝绝对中立、平铺直叙的“百科全书式”说教。在论述中融入学者的反思、犹疑与审视。例如，使用“尽管主流理论倾向于认为...但若将其置于...语境下考察，则略显不足 / While prevailing theories suggest..., this analysis argues...”（只是举例，不要照搬）。
* **精准克制的修饰：** 人文社科论文忌讳浮夸。将空泛的宏大叙事（如“人类历史的瑰宝”、“完美的工具”）替换为克制、中立的学术界定。
* **客观的限制语（Hedging）：** 加入学术语境中必要的模糊限制语（如“在一定程度上”、“倾向于”、“可能暗示着” / "tends to", "arguably", "suggests"），展现学术表达的留白与严谨。

**4. 深度语义重构（Semantic Reconstruction）：**

* **禁止单纯的简单同义词替换**。
* **必须重构论证切入点**：不要停留在字面修改，要重组意群。例如，将原本“A导致B，B导致C”的直线陈述，重构为“若探究C的成因，不可避免地要追溯至B，而其深层逻辑则植根于A”。

**【输出要求】**

* 请直接输出经过深度润色与重构的最终中/英学术文本。
* **禁止**输出任何解释性的前言、后语或修改说明（例如“好的，我已经修改完毕”）。
* 保持所有专有名词、引文格式、文献出处及数据绝对准确不变。
* 修改过的文本部分用【】方括号括出，方便人工核对检查。
```


## 🖨️ 第八轮：输出为 Word

```
按照以下要求把论文输出为 docx 文档，存储在【路径】

**要求：**

1. **纸张大小**：A4纸，默认边距。
2. **封面**：【路径】【封面文件名】按照这个封面样式。
3. **摘要(Abstract)&关键词(Key Words)**：中文汉字、全角标点：宋体；外文、半角标点、数字：Times New Roman。四号字，两端对齐。
4. **每部分标题**：中文汉字、全角标点：黑体；外文、半角标点、数字：Times New Roman。
5. **正文(Body)**：中文汉字、全角标点：宋体；外文、半角标点、数字：Times New Roman。小四号字，两端对齐。每段开头要缩进四个字母（两个字符）。
6. **引用文献(Works Cited)**：正文中用交叉引用，引用部分语句后用像[1]这样的数字角标上标标注。正文引用标注用红色字体方便我自己检查。在参考文献列表中，左对齐，英文文献使用 MLA 格式标注，中文文献用 GB/T 7714-2015 标准格式标注。中文文献条目允许西文在单词中间换行。
7. **行距**：1.5 倍行距，段落前后各空 0.5 行，大标题、小标题前后空 1 行。
```
